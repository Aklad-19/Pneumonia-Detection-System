# Pneumonia Detection System

A Flutter mobile app that screens chest X-ray images for pneumonia. The classifier is a TensorFlow Lite model that runs on the phone, so an X-ray never has to leave the device to be analysed.

Built as a university course project by a team of two.

> **Not a medical device.** The result is a model prediction, not a diagnosis. Always consult a qualified doctor.

## Features

- **Sign in** with email and password or with Google. New users can register. While you stay signed in, the app opens straight on the home screen.
- **Choose an X-ray** from the gallery or take a photo with the camera.
- **Detect:** runs the on-device model and shows *Pneumonia detected* or *Normal*, with the model's score.
- **Upload:** saves the X-ray to Firebase Storage and records it in Cloud Firestore under your user ID.
- **Donate:** a demo donation flow through the SSLCommerz payment SDK in sandbox mode (BDT 500).

## How detection works

1. The selected image is decoded and resized to 256 × 256 pixels.
2. Each red, green and blue value is scaled to the range 0–1.
3. The model (`assets/models/pneumonia.tflite`) takes a `[1, 256, 256, 3]` input and returns two scores: `[normal, pneumonia]`.
4. The class with the higher score is shown as the result.

Everything happens on the device. Uploading the image is a separate, optional step.

## Getting started

You need the Flutter SDK (with Dart 3.9.2 or later) and an Android device or emulator. Firebase is configured for Android and iOS.

```bash
git clone https://github.com/Aklad-19/Pneumonia-Detection-System.git
cd Pneumonia-Detection-System
flutter pub get
flutter run
```

### Firebase

The repository contains the configuration of the original Firebase project. To run the app against your own project:

1. Create a Firebase project and run `flutterfire configure` in this folder.
2. Turn on **Email/Password** and **Google** sign-in in Firebase Authentication.
3. Create a **Cloud Firestore** database and a **Storage** bucket.
4. For Google Sign-In on Android, add your debug SHA-1 fingerprint to the Android app in the Firebase console.

The app writes to these locations:

| Where | What |
|---|---|
| Storage: `xray_images/` | The uploaded X-ray, named `xray_<userId>_<timestamp>.jpg` |
| Firestore: `xray_uploads` | One document per upload: `userId`, `imageUrl`, `createdAt` |

## Limitations

- The donation flow is a demo. It opens the SSLCommerz sandbox and then confirms with a simulated payment step, so no real money moves.
- This repository contains the app and the trained model only. The training code and the model's test accuracy are not included.
- The model file is stored directly in git (not Git LFS), so cloning downloads about 58 MB.
